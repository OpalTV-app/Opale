# Opale
Opale est un lecteur IPTV gratuit pour Windows, simple, rapide et elegant.

Il est compatible avec les abonnements Xtream Codes. Il suffit d'entrer l'adresse du serveur, l'identifiant et le mot de passe fournis par votre fournisseur IPTV, et Opale organise automatiquement les chaines en direct, les films, les series et le guide des programmes.

Fonctionnalites : zapping instantane, apercu des chaines, guide TV, replay, reprise de lecture des films et series, favoris, recherche, choix des pistes audio et des sous-titres, gestion de plusieurs comptes.

Installation : telechargez le fichier zip dans la section Releases, faites un clic droit puis Extraire tout, ouvrez le dossier Opale et lancez Opale.exe. Si Windows affiche un avertissement, cliquez sur Informations complementaires puis Executer quand meme.

Important : Opale est uniquement un lecteur. Il ne fournit aucune chaine ni aucun contenu. Vous devez disposer de votre propre abonnement IPTV legal.
